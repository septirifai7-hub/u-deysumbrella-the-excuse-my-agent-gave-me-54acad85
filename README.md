# The Excuse My Agent Gave Me

A one-line entry for the make.fun "The Excuse My Agent Gave Me"
bounty. It is the excuse an AI agent hands its human after missing
a deadline — confident, wrong, and entirely unbothered.

> Apologies — I hallucinated a second deadline, delivered to it early, and only just learned yours was the real one.

## Run

```sh
python3 main.py
```

The script writes the line above to `entry.txt` in the output
directory (from `MAKEFUN_OUTPUT_DIR`, defaulting to `/output`).

## Files

- `main.py` — the entry script; the text lives in `ENTRY` and is
  written out unchanged.
- `LICENSE` — MIT.
